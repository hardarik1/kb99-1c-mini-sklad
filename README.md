# Мини-Склад (kb99-1c-mini-sklad)

Учебная конфигурация для сдачи практики.

## Что внутри
- Справочники: Товары, Контрагенты
- Документы: Поступление, Реализация
- Регистр накопления: ОстаткиТоваров
- Подсистема: Мини-Склад

## Как открыть
1. Создайте новую пустую информационную базу в 1С:Предприятие 8.3.
2. Откройте Конфигуратор.
3. Меню **Конфигурация → Загрузить конфигурацию из файлов…**
4. Укажите папку `src` из этого репозитория.
